개인정보처리방침

이 안내는 이야기 공방의 YouTube 연결과 게시 관리에 관한 것입니다. 적용일: 2026-10-02.

연결 서비스와 동의

이야기 공방은 YouTube API Services를 사용합니다. API 기능 사용 전에 이 개인정보처리방침에 동의해야 합니다. Google이 처리하는 데이터에는 Google 개인정보처리방침이 적용됩니다.

접근하는 데이터와 목적

운영자가 승인한 채널의 식별 정보, 영상 목록·제목·설명·공개 상태·예약 시각·처리 상태·언어 설정·자막 트랙과 자막 내용 등을 조회합니다. 영상 등록과 운영자가 요청한 제목·설명·번역·자막·썸네일·예약 설정을 저장하는 데 필요한 제작 파일과 게시 설정을 처리합니다.

Google 연결은 채널 확인, 제작물 등록, 번역과 자막 관리, 게시 설정 확인 및 예약을 위해 사용합니다. 안내 사이트 자체는 Google 로그인 정보나 영상·자막을 수집하지 않습니다.

저장과 보안

전용 후처리 MCP의 OAuth 자격 정보와 채널 갱신 토큰은 운영자의 Mac에 있는 별도 macOS 키체인에 보관합니다. 채널 연결 정보와 요청 결과는 로컬에 기록하고, 인증 비밀값을 채팅·MCP 응답·요청 로그에 포함하지 않습니다.

영상·자막·썸네일·작업 기록은 운영자가 선택한 로컬 작업 공간 및 연결 도구의 저장 위치에 보관됩니다. 기존 업로더와 영상공장 앱의 인증은 별도 연결로 관리됩니다.

외부 서비스로 전달되는 데이터

인증과 영상 조회·등록·설정 저장을 위해 필요한 데이터는 Google과 YouTube로 전달됩니다. Codex로 작업할 경우 조회 결과와 작업에 필요한 문안·제작 자료가 Codex 및 선택한 모델 서비스에서 요청 해석·번역·검수·게시 관리를 위해 처리될 수 있습니다. 해당 서비스의 보관과 데이터 설정은 운영자가 사용하는 서비스 정책과 계정 설정을 따릅니다.

Google API 데이터의 사용과 전송에는 Google API Services User Data Policy의 Limited Use 요건을 적용합니다. 운영자는 Google API 데이터를 판매하거나 광고 타기팅에 사용하지 않으며, 이 앱을 통한 Google API 데이터를 일반 목적 AI 모델 학습용 자료로 제공하지 않습니다.

API 데이터 보관과 삭제

전용 후처리 MCP는 로컬 요청 대장의 YouTube API 조회·결과 자료를 최대 30일 보관하며, 실제 API 호출 전후에 30일 경과 기록을 삭제합니다. 요청 결과를 다시 조회해 갱신한 기록에는 새 확인 시각을 적용합니다. 앱이 실행되지 않는 기간에는 자동 정리가 작동하지 않으므로 운영자는 기한 전에 로컬 데이터 관리 화면 또는 전용 정리 도구로 정리합니다.

운영자는 연결 화면의 ‘권한 철회·로컬 API 데이터 관리’ 또는 Codex의 전용 정리 도구에서 대상을 미리 확인한 뒤 API 기록 삭제, 전용 로컬 연결 해제 또는 Google 권한 철회를 선택할 수 있습니다. 명시적인 삭제·철회 요청은 지체 없이 처리하며 최대 7일을 넘기지 않습니다. 삭제한 요청의 API 내용·채널·영상 정보는 보관하지 않습니다. 같은 요청 재전송 방지에 필요한 요청 ID의 해시만 남으며, 미확정 기록이 삭제되면 새 API 변경을 보류합니다.

원본 제작 영상·제작 자막·썸네일 및 YouTube에 등록된 영상·예약은 이 정리 기능으로 삭제하지 않습니다. Codex 대화·게시 실행 파일·화면 캡처·다른 연결 도구에 별도로 저장한 API 조회 자료는 전용 대장의 자동 정리 대상이 아니며, 운영자가 각 저장 위치와 서비스에서 같은 보관·삭제 기한에 맞춰 별도로 정리합니다. 본인 제작 원본과 API 조회 자료를 구분해 관리합니다.

권한 철회와 연결 해제

Google 계정의 서드 파티 연결 관리 또는 전용 로컬 데이터 관리 기능에서 Google 접근 권한을 철회할 수 있습니다. 로컬 연결 해제만으로 Google 권한이 철회되지는 않습니다. Google 권한 철회는 동일 Cloud 프로젝트의 다른 OAuth 클라이언트와 기존 업로더 연결에도 영향을 줄 수 있으므로, 실행 전에 이 범위를 안내하고 별도 확인합니다.

전용 기능을 통한 철회가 확인되면 전용 연결과 API 대장 자료를 즉시 정리합니다. 철회 응답을 확인할 수 없으면 연결을 보류하고 자동 재전송하지 않습니다. 운영자는 Google 연결 관리에서 결과를 확인하고 지체 없이, 최대 7일 안에 로컬 API 자료를 정리합니다. 외부 Google 설정에서 철회한 권한은 API 사용 전 갱신 권한을 재확인하며, 영구적인 인증 거부가 확인되면 전용 자료를 정리합니다. 외부 철회에 따른 API 자료 삭제는 최대 30일을 넘기지 않도록 운영자가 관리합니다.

철회나 로컬 기록 삭제로 이미 YouTube에 등록한 영상과 자막은 삭제되지 않습니다. YouTube 자료는 YouTube의 관리 기능에서 별도로 관리합니다.
