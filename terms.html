이용 안내

이야기 공방은 운영자가 소유하거나 관리 권한을 가진 YouTube 채널에 사용하는 개인용 도구입니다.

YouTube 이용 조건

이 도구는 YouTube API Services를 사용합니다. 이용자는 이 도구를 사용함으로써 YouTube 서비스 약관의 적용에 동의합니다. 기능 사용 전 개인정보처리방침과 이 이용 안내를 확인하고 동의해야 합니다.

게시 작업

영상 등록과 게시 설정 저장은 운영자의 요청과 승인 범위에서 진행합니다. 예약 전에는 필수 설정과 실제 화면 검수를 확인합니다. API 응답이 불확실하면 현재 결과를 먼저 조회하며, 같은 변경을 자동으로 반복하지 않습니다.

예약과 실제 공개·재생 결과는 구분해 확인합니다. Google 인증 철회, API 할당량, 서비스 장애 또는 영상 처리 상태로 작업이 보류될 수 있습니다.

데이터 관리와 권한 철회

전용 API 대장 자료는 30일 보관 기한과 명시적 삭제 절차를 적용합니다. 앱이 실행되지 않을 때의 기한 관리 및 다른 도구로 내보낸 API 자료 정리는 운영자가 수행합니다. Google 권한 철회는 같은 Cloud 프로젝트의 기존 업로더 등 다른 클라이언트 연결에도 영향을 줄 수 있습니다. 실행 전 대상과 범위를 확인해야 합니다. 실제 영상·예약·제작 원본은 전용 로컬 정리로 삭제하지 않습니다. 자세한 방법과 기한은 개인정보처리방침을 따릅니다.

콘텐츠와 연결 서비스

운영자는 제작 자료와 게시물의 사용 권한, 사실관계 및 플랫폼 정책을 확인합니다. Google·YouTube·Codex 및 호스팅 서비스의 이용에는 각 서비스의 조건이 적용됩니다.
