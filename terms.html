게시 작업

영상 등록과 게시 설정 저장은 운영자의 요청과 승인 범위에서 진행합니다. 예약 전에는 필수 설정과 실제 화면 검수를 확인합니다. API 응답이 불확실하면 현재 결과를 먼저 조회하며, 같은 변경을 자동으로 반복하지 않습니다.

예약과 실제 공개·재생 결과는 구분해 확인합니다. Google 인증 철회, API 할당량, 서비스 장애 또는 영상 처리 상태로 작업이 보류될 수 있습니다.

콘텐츠와 연결 서비스

운영자는 제작 자료와 게시물의 사용 권한, 사실관계 및 플랫폼 정책을 확인합니다. Google·YouTube·Codex 및 호스팅 서비스의 이용에는 각 서비스의 조건이 적용됩니다.
